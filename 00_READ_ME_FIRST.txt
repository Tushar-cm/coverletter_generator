🔑 GET API KEY (Optional for Real AI)

Google Gemini (FREE) - Recommended
1. Go to: https://ai.google.dev/
2. Click "Get API Key"
3. Copy your key (starts with AIz...)
4. Open: backend/.env
5. Replace: GEMINI_API_KEY=your_key_here
6. Restart server

OpenAI (Paid) - Alternative
1. Go to: https://platform.openai.com/api-keys
2. Create new secret key
3. Copy your key (starts with sk-...)
4. Open: backend/.env
5. Uncomment and add OpenAI key
6. Change: AI_PROVIDER=openai
7. Restart server

Test Without Key (Mock AI)
- Keep .env as-is
- Use "🎭 Mock AI" mode
- Works instantly with templates

A: Yes! They work in parallel. Choose in .env
